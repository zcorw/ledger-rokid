# 知产 Rokid

[English](README.md) | **简体中文**

Rokid AIUI 收据拍摄与识别智能体，配合 Flow Ledger 2 使用。

- 打开智能体先检查已保存的绑定。未绑定时先显示手机绑定网址和绑定码，不打开相机；绑定完成或已有绑定时，自动显示实时取景，下方提示“单击拍照，自动识别账单”。
- 单击后先释放预览相机，再以 `default` 全视角模式拍摄高质量照片并自动识别；识别期间显示照片。预览与成片范围仍需在眼镜上对照验收，尚未确认完全一致。
- 首次使用需在拍照前，通过手机登录[知产设备授权页](https://ledger.zcorw.xyz/receipt-devices)，输入眼镜上的绑定码并确认。授权仅用于收据识别，长期有效，直到撤销或修改账号密码。凭证保存在按 Agent 隔离的本地存储中，退出或重启眼镜后自动恢复；清除 Agent 数据后需重新授权。
- JPEG、PNG、WebP 原始字节不转换，经 HTTPS 上传，与识别单据一起私有保存在 VPS；后端只对识别副本另行转换。识别成功后以 `preview/index.html` 的独立整屏滚动布局展示实际账单内容，突出金额和货币符号。未确认字段（含金额）直接留空，不填示例值或占位符，不自动保存开销。
- 网站 **每日开销 → 识别单据** 可回看原图，保存开销时可继续关联；此前未上传或未保存的照片无法补回。
- 取消、隐藏或退出会停止预览、清除本地照片并取消网络请求；这不会删除服务端已经保存的原图。识别失败可重试同一照片或重新拍摄。
- 语音修改账单值保留为待办，暂未实现，也不申请麦克风权限。

两端代码需配套部署。Flow Ledger 2 必须先迁移到 `0013_receipt_originals` 并部署设备授权页面/API；设置 `APP_BASE_URL=https://ledger.zcorw.xyz`，并配置后端识别服务。眼镜无法使用仅支持网页登录的旧版后端。详见[智能体流程](docs/AGENT-FLOW.md)、[接口约定](docs/OCR-CONTRACT.md)和[设备验收](docs/DEVICE-ACCEPTANCE.md)。

## 本地检查

使用 Node.js 22 或更新版本：`npm run check`、`npm test`。通过 `npm ci --ignore-scripts` 安装开发依赖。测试使用合成照片和返回值，不联系生产识别服务；需在支持的原生 AIUI 运行时编译、同步资源包并验收。

## 独立浏览器演示

[账单编辑演示](docs/REVIEW-PROTOTYPE.md)保留逐字段编辑及显式确认；`/preview/chain.html` 提供拍摄、识别、编辑、提交的完整合成流程。它们不属于原生智能体注册页面，不调用相机或实际后端。浏览器只保存合成操作的恢复数据，详见[演示范围](docs/SYNTHETIC-CHAIN.md)。CI 的 Chromium 检查不能替代眼镜验收。
