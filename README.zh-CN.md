# 知产 Rokid

[English](README.md) | **简体中文**

Rokid AIUI 收据拍摄与识别智能体，配合 Flow Ledger 2 使用。

开发分支按手绘草图排版：商户、金额、时间、账户固定四行，字段名和值同行；分类放在金额右侧。七个字段标签即使值为空也保留，语音修改、草稿、确认横排固定在底部。商户文字占用明确宽度并保留右侧空隙，长名称换行后在本行区域内纵向滚动；其他长内容在各自区域内横向滚动。已确认币种的代码随符号显示；未知币种明确提示待确认。滑动选择底部操作，头部动作选择字段，详见[流程与验收](docs/REVIEW-WORKFLOW.zh-CN.md)及 [TODO.md](TODO.md)。新包真机验收与代码完成分别记录。

- 打开智能体先检查已保存的绑定。未绑定时先显示手机绑定网址和绑定码，不打开相机；绑定完成或已有绑定时，自动显示实时取景，下方提示“单击拍照，自动识别账单”。
- 单击后先释放预览相机，再以 `default` 全视角模式拍摄高质量照片并自动识别；识别期间显示照片。预览与成片范围仍需在眼镜上对照验收，尚未确认完全一致。
- 首次使用需在拍照前，通过手机登录[知产设备授权页](https://ledger.zcorw.xyz/receipt-devices)，输入眼镜上的绑定码并确认。授权仅用于收据识别，长期有效，直到撤销或修改账号密码。凭证保存在按 Agent 隔离的本地存储中，退出或重启眼镜后自动恢复；清除 Agent 数据后需重新授权。
- JPEG、PNG、WebP 原始字节不转换，经 HTTPS 上传，与识别单据一起私有保存在 VPS；后端只对识别副本另行转换。识别成功后在实际注册的拍摄页中以四行审核布局展示账单内容。未确认字段（含金额）直接留空，不填示例值或占位符，不自动保存开销。
- 网站 **每日开销 → 识别单据** 可回看原图，保存开销时可继续关联；此前未上传或未保存的照片无法补回。
- 点击 **草稿** 将当前候选保存到同一原图记录，不重复上传、不创建开销。重复点击复用操作键，响应不明时先查询再重试。网站可筛选未入账草稿或搜索商户后继续编辑。需要先执行后端迁移 `0014_receipt_drafts`，并部署配套网站/后端。
- 点击 **确认** 需要完整审核字段，以及手机单独核对并允许此设备入账；旧识别授权不会自动升级。服务端复用既有开销写入逻辑并核对草稿版本，重复点击、重试和重启恢复不会为同一单据重复记账；疑似重复需再次明确确认。本地恢复只保存绑定后端的单据/版本/请求 ID，明确重试前先查询结果，不保存单据字段或照片。手机可单独撤销入账权限，成功后可选择 **继续拍摄**。
- 取消、隐藏或退出会停止预览、清除本地照片并取消网络请求；这不会删除服务端已经保存的原图。识别失败可重试同一照片或重新拍摄。
- 点击 **语音修改** 后才持续收音，并实时显示识别文字（含可能修订的临时文字）。原按钮切换为 **结束收音**，草稿位置切换为 **取消**；停顿或分段完成不会自动提交。手动结束会收齐最后一段并等待完整最终转写，再将文字和当前候选经鉴权送到后端修正。意外结束、转写不完整或错误时保留可见文字和候选，不提交分析；取消会中止收音或分析。最终识别文字随结果保留到重拍、隐藏或退出，不记日志、不保存到本地存储。语音修改不会保存草稿或开销。本分支声明 `RECORD_AUDIO`；不支持语音的运行时可在网站继续编辑。

两端代码需配套部署。安装本包前，Flow Ledger 2 必须迁移到 `0015_device_expense_grants` 并部署配套网站/API；设置 `APP_BASE_URL=https://ledger.zcorw.xyz`，并配置后端识别服务。旧后端不能提供新的审核流程。详见[新审核流程](docs/REVIEW-WORKFLOW.zh-CN.md)、[智能体流程](docs/AGENT-FLOW.md)、[接口约定](docs/OCR-CONTRACT.md)和[设备验收](docs/DEVICE-ACCEPTANCE.md)。

前后滑动只选择底部按钮；抬头、低头、左转头、右转头按页面实际行列选择七个字段（商户；金额/分类；时间/币种；账户/备注），字段到边界后停留，不绕行。按钮和字段分别记住位置：从字段第一次滑动时，只恢复上次按钮，不额外移动；从按钮第一次做头部动作时，只恢复上次字段，后续动作再移动。单击/Enter 编辑当前字段。使用[官方方向传感器](https://open.rokid.com/aiui/api/device/absolute-orientation-sensor?lang=zh-CN&version=0.19.0)的相对姿态：静止250毫秒建立基准，抬头/低头/转头超过12度并保持120毫秒触发一步，回到5度范围并保持150毫秒后才可再次触发；持续保持头部姿态不连跳，细小、短暂或方向不明确的斜向动作不移动。传感器可用性、真机安装轴向及阈值仍需眼镜验收；不支持时显示提示，底部按钮仍可使用。隐藏/退出、整单语音和财务锁定期间停止采样。字段语音页保留当前值、实时文字与全部合法候选，采用四列，12个分类可在紧凑卡片同页展示；长列表改用抬头/低头同页滚动。滑动选择结束/重试或取消，单击/Enter执行，返回取消。编辑或取消后回到记住的字段，不覆盖底部按钮的位置记忆；歧义保留选项和原值。账户ID/名称视为同一字段，原语音修改按钮仍可修改整单。

头控诊断优先使用[页面级环境感知接口](https://open.rokid.com/aiui/api/framework/page?lang=zh-CN&version=0.19.0)，独立方向传感器作为兼容回退。在账单渲染回调中启动，兼容事件自身的四元数、x/y/z/w和实例属性。可见状态区分等待数据、平视校准、已就绪及上下/左右相对角度、等待回正，以及不可用、数据无效或中断；3秒没有有效首帧或数据停止时明确提示，不再静默等待。同一状态每秒最多更新两次，停止时清理计时器/监听并忽略迟到事件。语音页故障提示复用原说明行，保留12个候选同页展示空间。这是接入兼容和可观测性修正，尚不能据此认定1.2.3真机失效的根因是传感器、运行时或阈值，仍需新包真机验收。

配套后端新增 `GET /review-options`（版本 1，完整分类、启用币种及所属启用账户），`POST /review-correction` 支持可选 `targetField`，定向响应增加 `fieldOutcome`：`matched`、`unchanged`、`ambiguous`、`unmatched`。前后端均限制字段边界。有限选项先按规范化名称/别名精确匹配，再按唯一包含项及保守文字相似度匹配（至少 0.72，领先次项至少 0.15）；多项接近或否定指令需澄清，不等于通用拼音/语义匹配。自由字段沿用模型但明确目标，并丢弃其他字段修改，不写账。候选仅存内存，隐藏/退出时清除。安装原生新包前须部署这项后端增量，候选接口缺失/无效时明确失败；未传目标字段的旧请求保持原行为。

语音结果展示修改的字段，商户发生变化时还显示修改后的全名。完整的单独商户指令与当前名称完全相同且没有警告时，提示“商户已是 SEIYU，无需修改”。其他未产生变化的结果会提示核对识别文字、显示当前商户并保留服务端警告，不仅凭修改字段为空就断言指令与当前值一致。

## 本地检查

使用 Node.js 22 或更新版本：`npm run check`、`npm test`。通过 `npm ci --ignore-scripts` 安装开发依赖。测试使用合成照片和返回值，不联系生产识别服务；需在支持的原生 AIUI 运行时编译、同步资源包并验收。

运行 `node qa/review-layout.mjs`，检查实际原生模板在 448×150、480×168、320×240、480×320、640×360 下的布局。高度不足 200px 时使用紧凑间距和字号，保留全部审核字段与按钮；包含发布前实际观察到的 480×168 云端卡片。收音/分析时，字段区域切换为转写面板，结束/取消按钮保持可操作。`REVIEW_CHROMIUM_PATH` 指定已安装的 Chromium 浏览器，`REVIEW_SCREENSHOT_DIR` 保存合成预览；160 组几何检查也在 CI 运行，覆盖空值、长内容、商户首尾字符边界（拉丁字母、中文及混合名称）、滚动、无变更提示、授权提示及手动收音状态。本地 AIX 不会自动更新云端 Agent 或眼镜。需在既有云端 Agent 导入并重新打包，再通过手机更新眼镜资源包，记录实际安装版本后验收。
