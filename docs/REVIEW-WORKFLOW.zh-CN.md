# 单据审核流程

[English](REVIEW-WORKFLOW.md) | **简体中文**

用户于 2026-11-17 验收了此前的拍摄/识别包。本次新增审核布局、语音修正、草稿和明确授权后的入账；本地测试及打包不代表眼镜已经安装或验收新功能。

审核界面在实际注册的拍摄页中。按用户手绘草图固定四行：商户、金额、时间、账户，分类在金额右侧；字段名和值同行。值缺失时仍保留五个标签，三个操作横排固定在底部。长内容只在各自限定区域内横向滚动，不把其他字段/按钮挤出屏幕；反馈提示有独立的限定纵向滚动区域。已确认币种代码区分 JPY/CNY、USD/CAD，不从有歧义的符号推断币种。方向键定位，Enter/单击只触发一次。财务结果不明时禁止继续修改，先核对结果。

语音修改在用户操作中启动持续 `SpeechRecognition`，启用临时结果；实时文字会替换修订片段，不重复追加累计结果。收音/分析时字段区切换为转写面板，结束收音和取消可通过点击或方向键/Enter操作。第一段最终结果或停顿不会结束收音或发请求。用户必须选择结束收音：调用 `stop()` 收齐剩余音频，等最终文字及结束事件后，才把完整转写和当前字段发送到修正接口。仅最终转写等待设置10秒超时，持续收音没有应用计时器。意外结束、仍有临时文字、空白/超长文字或错误时，保留可见文字和原账单，不静默提交半句话。取消、隐藏、退出会中止收音或分析并忽略迟到事件；按键/点击的重叠事件不会把开始变成结束，或把取消变成保存草稿。最终文字随结果保留到重拍、隐藏或退出，仅存于内存；音频/转写不记日志、不写本地存储。不支持该能力或权限失败时保留候选，并提示可在网站编辑。后端模型不能保存或提交账务；展示已修改字段及提示。账户名称须唯一匹配所属的启用账户，不猜测同名或不明确账户。

草稿在已有原图单据上保存当前字段，稳定操作键与版本校验保护重试和旧页面覆盖。保存响应丢失时查询结果，失败保留候选。网站识别单据页可筛选/搜索草稿、查看原图、继续修改后明确创建关联开销。原始 OCR 字段和原图字节与修正草稿分别保存。

确认要求金额、时间、ISO 币种、分类、账户完整。未启用入账时，眼镜显示手机设备授权链接；打开链接不会授权，登录后的账户主人必须核对指定设备、阅读提示、勾选确认并授权。单独撤销入账权限不会撤销识别/草稿访问；设备凭据仍不能访问普通资产或管理接口。

确认的草稿版本通过既有已验证提交状态机及后端开销写入逻辑提交。已有开销会返回同一记录，不重复创建；删除墓碑仍生效。疑似重复需再次明确触发。权限检查、保存草稿和提交期间禁止并发编辑；取消、隐藏、退出屏蔽迟到结果，并保留财务结果不明的状态。

财务请求发送前，Agent 隔离存储只保存 `{version, resource, receiptId, revision, requestKey}`，不含图片、字段、语音文本或供应商密钥；存储失败会阻止发送。重启先查询服务端结果，已入账无需再次 POST；未入账则恢复服务端草稿，等待用户明确确认后复用相同请求键。草稿改变时展示新内容并重新核对。成功后选择继续拍摄以开始新单据。

先将配套网站/后端迁移到 `0014_receipt_drafts`、`0015_device_expense_grants` 并部署，再安装本资源包；不自动为旧设备开启入账。使用 `npm run check`、`npm test`、`node qa/review-layout.mjs` 本地检查，`REVIEW_CHROMIUM_PATH` 可指定已安装的 Chromium 浏览器。自动化使用合成数据及替代语音/模型回复。

旧版金额优先页面和独立浏览器演示都不是此原生审核布局。本地打包 AIX 不会改变已安装资源；手机/眼镜同步前，需在既有云端 Agent 导入源码或资源包并重新打包，不使用 CLI 本地开发标识替换既有身份。记录云端包及实际安装版本，部署和新版真机验收仍待执行。

新包真机需覆盖：五标签同行、分类与金额同排、空值、长内容滚动、底部按钮与焦点；麦克风权限、实际转写及歧义指令；网站草稿与原图；手机独立入账授权/撤销；成功确认与重复提示；中断/迟到请求及 Agent/设备重启；语音修改/草稿不改变账务且无重复开销。验收时记录实际固件与资源包版本。
